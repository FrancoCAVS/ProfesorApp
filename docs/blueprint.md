# **App Name**: Professor's Friend

## Core Features:

- Event Scheduling: Allow teachers to schedule events (exams, meetings, holidays, etc.) with date, time, title, description and reminder options.
- Subject Management: Enable teachers to manage subjects, including name and grade level.
- Absence Tracking: Allow teachers to record student absences by date, student name, and subject.
- AI-Driven Suggestions: AI powered tool which intelligently suggests event titles and descriptions based on event type and context, improving the efficiency of event creation.
- User Interface: Friendly and clear user interface with easy navigation of the key sections: Calendar, Subjects and Absence Tracking.

## Style Guidelines:

- Primary color: Deep sky blue (#3399FF), symbolizing knowledge and trust.
- Background color: Very light blue (#EBF5FF), almost white, for a clean, uncluttered interface.
- Accent color: Vivid cyan (#00FFFF) to highlight important actions and dates in the calendar.
- Headline font: 'Space Grotesk', sans-serif, to convey modernity. Body text: 'Inter', sans-serif.
- Use simple, flat icons in a single style to represent subjects and event types.
- Use a clean and organized layout with clear visual hierarchy.
- Subtle transitions and animations to provide feedback.
